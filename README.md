# Super Awesome Datapacks

Super Awesome Datapacks is a private collection of Minecraft Java Edition system reworks for a small server of roughly 5-10 friends. The packs change parts of Minecraft that we find random, tedious, or overly restrictive without turning the game into something unfamiliar to a vanilla player.

The project targets Minecraft Java Edition 26.3. Super Awesome Enchanting is ready for private-server playtesting. Super Awesome Villagers remains in design.

## Design principles

- Keep vanilla progression recognizable. Punching a tree, upgrading tools, finding Diamonds, visiting the Nether, and reaching the End remain the backbone of the game.
- Reward different playstyles without making one mandatory. Farming, optimization, exploration, and trading should each be useful.
- Treat Villager trading as a secondary way to get resources, not the only sensible way.
- Balance around a small multiplayer server where players have different skill levels and nearby structures may already have been looted.
- Keep each system rework playable on its own. Packs may integrate when installed together, but none should require another pack in this collection.
- Keep gameplay usable without a resource pack. A companion resource pack may improve presentation, but it must remain optional.

## Possible future packs

The notebook also contains early ideas for Beacons, death and item recovery, stackable Potions, earlier Shulker access, and survival-friendly replacements for commands such as `/home` and `/tp`. These are possibilities, not commitments. Enchanting and Villagers are the current focus.

## Documentation

The READMEs describe the current intended design, including features that have not been implemented. Sections labeled as open design work are unresolved. The Obsidian notebook remains a place for rough thinking; once an idea is settled and brought into this repository, the repository documentation is authoritative.
