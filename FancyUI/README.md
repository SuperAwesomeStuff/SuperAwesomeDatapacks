# Private FancyUI compatibility pack

This is the FancyUI runtime used by Super Awesome Enchanting. Install the `FancyUI` and `SuperAwesomeEnchanting` directories next to each other in the world's `datapacks` directory.

This copy differs from upstream FancyUI in a few narrow ways:

- It uses Minecraft Java 26.3 data formats.
- It uses vanilla Stone Buttons and Gray Stained Glass Panes instead of custom item models.
- Button names and lore work without a resource pack.
- Fixed controls are recovered by their `fancyui.fixed` marker instead of a hard-coded item list.

Do not redistribute this directory. See `PRIVATE_USE_NOTICE.md` for the permission boundary and upstream project link.
